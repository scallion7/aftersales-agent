## 如何重新生成

在虚拟环境中安装项目锁定依赖和对应 Chromium。以下命令按 Bash/zsh 编写。

```bash
python -m pip install -r requirements-lock.txt
python -m playwright install chromium
python -m docs.showcase.record_demo --output test-results/showcase-recording-01
```

PowerShell 在激活虚拟环境后使用同一条 `python -m docs.showcase.record_demo ...` 命令。若设置过 `PLAYWRIGHT_BROWSERS_PATH`，安装和录制须使用相同目录。

这个[复录工具](record_demo.py)调用现有[浏览器回归](../../tests/test_platform_http.py)，将浏览器操作间隔设为 900 毫秒、页面视口和录像设为 1366 × 1000，不改变业务断言。可用 `--step-ms 1500` 调整讲解节奏。工具拒绝已存在的输出目录，失败时保留现场供诊断。

浏览器回归负责创建临时数据库、启动并停止服务、检查页面脚本错误、核对唯一工单，并在关闭浏览器上下文后输出两个 `.webm` 和两张 `.png`。工具另外写入 `recording.json` 记录参数与结果。数据库与服务临时目录会被清理，录制目录保留。

预期输出为 `Ran 1 test` 和 `OK`，四个素材应非空。工具自动启用浏览器测试；若出现跳过、失败或缺少素材，会以非零退出，不能记录为录制完成。

## 讲解与使用顺序

1. 先展示[项目卡](project-card.md)，用一句话交代业务场景与模型、业务服务的职责。
2. 播放客户短片，可在政策引用和“确认并执行”处暂停，解释原文定位和参数绑定。
3. 播放客服短片，在接管、人工回复处暂停，说明旧任务的新调用会受到所有权检查约束，已经在途的外部请求仍需对账。
4. 按[三项演示](demo.md)补充退款恢复与评测拒绝发布。打开报告或测试断言，说明实际验收条件。
5. 结束时展示验收页，区分本地测试、受控模型矩阵、真实模型待审核事项。

自动录制会等待界面状态并放慢操作，讲解时仍可在关键画面暂停；制作配音视频时按上述分镜加停顿，保留“受控模型 / 合成数据”说明。

## 更新素材的检查

- 先复录到新的 `test-results/` 子目录，核对界面、工单终态和页面错误，再选取素材进入新的证据批次。
- 记录生成所用 Git 基线、是否存在未提交源码、测试命令、浏览器版本和文件哈希。旧批次保持原样。
- 只收录隔离演示数据，不录入个人 `.env`、真实访问令牌、订单或用户信息。
- 同步更新本页和[证据索引](../evidence/README.md)。录制不等于真实模型效果验证。
